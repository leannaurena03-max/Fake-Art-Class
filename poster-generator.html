Fonts & Illustrator

Keep poster-generator.html beside a fonts/ folder containing:

  • Anton-Regular.ttf
  • Oswald-VariableFont_wght.ttf
  • BebasNeue-Regular.ttf
  • LeagueGothic-Regular-VariableFont_wdth.ttf

Keep the fonts’ original licenses with them. Upload this page and the folder together to GitHub Pages. If opening directly from your computer blocks fonts, use GitHub Pages or a local web server.

For Illustrator, install the font selected for that poster: Anton Regular, Oswald (headline weight 700), Bebas Neue Regular, or League Gothic (default width). Installing all four lets you inspect every variation. Embedded browser fonts do not replace desktop installation in Illustrator.

Open the SVG in Illustrator and check that the Type tool edits the words and that rectangles remain separate vector shapes. This app does not outline or flatten the artwork.
